# Disk-Info
Permet d'afficher les données SMART des supports de stockage sous Linux

Sous Debian, les 3 paquets suivants doivent être présents :  
python3-tk  
python3-pil.imagetk  
smartmontools

## 🤖 Crédits et Remerciements
Ce projet a été conçu et développé en collaboration avec un assistant IA pour la structuration du code Python/Tkinter et l'optimisation de la gestion des commandes `smartctl`.
